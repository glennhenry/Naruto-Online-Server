Command

Command is a tool that allows you to instruct the server to do certain actions implemented in server code.

The left side shows you the output, while on the right side you can choose the command to invoke and input its arguments.

Some arguments are required meaning you must fill them before proceeding while some are optional. The default value will be used if you leave an optional argument empty.

Made possible by Encore, a game server framework. Bring it back live.
